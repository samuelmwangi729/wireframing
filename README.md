# Introduction to Wireframing
- A wireframe is a skeleton that defines how the application or the website will look like.
- It Outlines the basic structure and the layout of the app without delving into much more details

# Key Elementss of Wireframing
- Navigation 
    This shows how the users will be able to navigate through the app and also exit the app
- Layout Structure
    This defines the structure of the application being build. This gives time for modification earliy rather than waiting for the design to be complete then modification starts.
- Content Placement
    This dictates how the content will be placed in relation to the pages. Images and graphical objects are replaced by boxes
- Functionality
    Details on how the application will function

# Types of Wireframes

    - Low Fidelity wireframes
        They are wireframes that are very simply. They are drawn using a pen and paper and they are not detailed

    - High level Wireframe
        They are detailed designs with most of the features present. They are closer to the final design.
